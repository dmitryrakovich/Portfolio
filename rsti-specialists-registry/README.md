# РСТИ — Реестр специалистов

**Системный анализ • Сбор и формализация требований • UI • Тестирование**

## О проекте

Проект по разработке функциональности модуля «Реестр специалистов по технической инвентаризации» в рамках технологической практики.

Система предназначена для работы с реестром специалистов и обработки заявок на создание и изменение учетных записей.

## Что было сделано

- сбор и анализ требований;
- разработка функциональных требований;
- описание пользовательских сценариев;
- проектирование поиска и фильтрации данных;
- описание работы с заявками;
- проектирование интерфейса;
- подготовка прототипов;
- подготовка тест-кейсов.
