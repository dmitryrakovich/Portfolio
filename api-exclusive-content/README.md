
# Otium — API Analysis & Exclusive Content

### API Analysis • Microservices • XML/SOAP • Sequence Diagram • Backend Task

## 📌 О проекте

Проект анализа API стримингового сервиса Otium.

В рамках проекта необходимо реализовать возможность отображать
пользователям список фильмов и сериалов, доступных эксклюзивно
на платформе Otium.

Сервис построен на микросервисной архитектуре и включает
отдельные сервисы для работы с пользователями, подписками,
оплатой, фильмами и сериалами.

Для получения контента используется API-слой, который
взаимодействует с микросервисами Films Server и Series Server.

## 🎯 Цель проекта

Проанализировать существующую архитектуру и API Otium,
определить необходимые изменения для реализации фильтрации
контента по признаку эксклюзивности и сформировать задачу
на доработку backend API.

## 🏗 Архитектура

В архитектуре Otium выделены следующие компоненты:

- UI приложения;
- Web Server;
- Films Server;
- Series Server;
- User Server;
- Subscription Server;
- Payment Server.

Для реализации функции используются:

**UI → Web Server → Films Server / Series Server**

Web Server выполняет роль API-слоя между пользовательским
интерфейсом и микросервисами контента.

## 🔄 Анализ Sequence Diagram

Для получения общего списка фильмов и сериалов Web Server
параллельно обращается к:

- Films Server;
- Series Server.

Использование параллельного взаимодействия позволяет получить
оба типа контента и сформировать единый список для отображения
в интерфейсе.
