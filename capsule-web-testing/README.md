# Capsule — Web Application Testing

### Test Planning • Test Cases • Functional Testing • Defect Analysis

## 📌 О проекте

Проект функционального тестирования веб-версии сервиса
бронирования капсульных отелей «Капсула».

Тестировалась версия приложения 2.2.

В рамках проекта была проведена проверка основных пользовательских
сценариев:

- регистрация пользователя;
- работа личного кабинета;
- бронирование отеля;
- просмотр истории бронирований;
- редактирование контактных данных;
- отмена бронирования;
- работа карты с расположением отелей.

## 🎯 Цель проекта

Проверить соответствие реализованной функциональности
предъявляемым требованиям и выявить несоответствия между
ожидаемым и фактическим поведением системы.

## 🧪 Тест-план

В рамках проекта был разработан и дополнен тест-план,
включающий 12 функциональных тестов.

Каждый тест содержит:

- идентификатор;
- тестируемое требование;
- цель;
- идентификатор интерфейса;
- последовательность действий;
- тестовые данные;
- ожидаемый результат;
- фактический результат.

## 🔍 Покрытые сценарии

### Регистрация

Проверены:

- регистрация с валидными данными;
- валидация обязательных полей;
- подсветка невалидных полей;
- проверка совпадения паролей;
- повторная регистрация существующего пользователя.

### Бронирование

Проверены:

- бронирование неавторизованным пользователем;
- создание личного кабинета при бронировании;
- бронирование авторизованным пользователем;
- автоматическое заполнение контактных данных;
- расчёт стоимости бронирования.

### Личный кабинет

Проверены:

- просмотр истории бронирований;
- редактирование контактного телефона;
- редактирование email;
- отмена запланированного бронирования.

### Карта

Проверены:

- открытие раздела «Где найти»;
- отображение отелей;
- получение информации об отеле;
- отображение ближайших станций метро;
- изменение масштаба карты.

## 🐞 Выявленные проблемы

В ходе тестирования были выявлены следующие несоответствия:

### Карта

При выборе отеля на карте информация об адресе
и ближайших станциях метро не отображается.

Также невозможно определить расположение отеля
с помощью изменения масштаба из-за неработающей карты.

### Регистрация

Пользователь успешно регистрируется, однако письмо
с подтверждением регистрации не приходит на указанный email.

### Бронирование

Неавторизованный пользователь может оформить бронирование,
однако после бронирования не получает ожидаемое уведомление
на email.

### Личный кабинет

Авторизованный пользователь может изменить номер телефона,
но возможность редактирования email отсутствует.

### Отмена бронирования

Отменить запланированное бронирование невозможно из-за
неработающей кнопки «Отменить бронирование».
