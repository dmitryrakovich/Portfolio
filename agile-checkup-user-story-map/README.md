# Agile Check-up — User Story Map & MVP

### Agile • User Story Mapping • Backlog • MVP • Product Analysis

## 📌 О проекте

Проект по разработке функции «Чекап» для мобильного приложения
сети медицинских клиник «Вита».

Функция предназначена для формирования персонального плана
профилактического обследования пользователя на основании его
возраста, пола и имеющихся заболеваний.

План чекапа включает необходимые консультации врачей и
лабораторные исследования, а также позволяет пользователю
контролировать прохождение рекомендаций.

В рамках проекта разработана карта пользовательских историй
(User Story Map) и выделен минимально жизнеспособный продукт (MVP).

## 🎯 Цель проекта

Определить пользовательский путь при работе с функцией «Чекап»,
структурировать требования в формате User Story Map и определить
минимальный набор функциональности для проверки продуктовых
гипотез.

## 👥 Пользовательские цели

Основные цели пользователей:

- получить персональный план чекапа;
- понимать, какие обследования необходимо пройти;
- записываться к врачам;
- контролировать прохождение чекапа;
- отслеживать прогресс;
- получать уведомления о необходимых действиях;
- при необходимости контролировать прохождение чекапа близкими.

## 🗺 User Story Map

Карта пользовательских историй построена по принципу:

**Активность → Задача → Пользовательская история**

В карте выделены основные пользовательские активности:

- формирование плана чекапа;
- планирование прохождения чекапа;
- контроль прохождения чекапа;
- контроль чекапа близких.

Для каждой активности определены задачи пользователя
и соответствующие пользовательские истории.

### Основные пользовательские истории

Примеры историй:

- Как пользователь, я хочу ввести данные, чтобы сразу получить
  план чекапа.
- Как пользователь, я хочу сразу получить план чекапа, чтобы
  понимать, что делать дальше.
- Как пользователь, я хочу записаться к врачу, чтобы выполнить
  рекомендации.
- Как пользователь, я хочу видеть прогресс, чтобы понимать,
  на каком этапе я сейчас нахожусь.
- Как пользователь, я хочу получать уведомления, чтобы не
  пропустить приём.

## 🚀 MVP

В качестве MVP выделен минимальный набор пользовательских историй,
необходимый для прохождения основного сценария работы с чекапом.

В MVP вошли 5 историй:

1. Ввод данных пользователя и получение плана чекапа.
2. Просмотр сформированного плана чекапа.
3. Запись к врачу для выполнения рекомендации.
4. Просмотр прогресса прохождения чекапа.
5. Получение уведомлений о необходимых действиях.

Такой набор позволяет пользователю пройти основной сценарий:

**ввод данных → получение плана → выполнение рекомендаций →
контроль прогресса → получение напоминаний.**

Остальные функции остаются в бэклоге и могут быть реализованы
на следующих этапах развития продукта.
